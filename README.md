# bigdata-analysis-cert-simulation

DataQ 실기 체험 UI를 참고한 **빅데이터분석기사 실기** 연습 앱입니다.  
**프로젝트(문제은행)** 와 **시험(응시)** 은 저장/ZIP 포맷이 분리되어 있습니다.

제13회 빅데이터분석기사 실기 응시 가이드(2026.11.28) 기준으로 문항·배점·환경을 맞춥니다.

## 공식 시험 구성 (제13회)

| 구분 | 문항 수 | 배점 | 제출 |
|------|---------|------|------|
| 제1유형 | 3 | 문항당 10점 (합 30) | 풀이 후 **답안 제출** 화면(단답) |
| 제2유형 | 1 | 40점 (5점 단위 구간) | 코드 실행 → CSV (`result.csv`) |
| 제3유형 | 2 | 문항당 15점 (합 30) | 풀이 후 **답안 제출** 화면(단답) |
| 합계 | 6 | 100점 | — |

- 시험 시간: **180분**
- 코드 실행: **1회 60초**, 초과 시 강제 취소
- 환경: Python / R 선택, 자동완성·단축키 미제공(체험 UI)

## 시작

```bash
bun install
bun run dev
```

| 경로 | 역할 | 패키지 |
|------|------|--------|
| `/` | 홈 | — |
| `/project` | CSV 라이브러리 · 문제은행 · 시험 조립 | `*.project.zip` (`project.json`) |
| `/exam` | 응시 · 실행 | `*.exam.zip` (`exam.json`) |

## 워크플로

1. **프로젝트**에서 CSV를 여러 개 라이브러리에 넣음  
2. 문제은행에서 문제 작성/복제, 문제마다 사용할 CSV 체크  
3. 시험 조립 시 공식 구성(3+1+2) 체크리스트 확인 후 **시험 ZIP 내보내기** 또는 **시험으로 보내기**  
4. **`/exam`** 에서 `.exam.zip` 만으로 풀이 (프로젝트 편집과 분리)

## 빌드
